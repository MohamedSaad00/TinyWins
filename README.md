# TinyWins

TinyWins is a simple yet effective application designed to help users track their small achievements daily. The goal is to encourage positive reinforcement by celebrating progress, no matter how small.

## Features
- **Log Wins**: Easily add and track small victories.
- **View History**: Keep a record of past achievements.
- **Minimalist UI**: Clean and simple user experience.
- **Local Storage**: Data persists between sessions.

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/TinyWins.git
   ```
2. Navigate to the project folder:
   ```sh
   cd TinyWins
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Run the application:
   ```sh
   npm start
   ```

## Usage
- Click the **Add Win** button to record a small achievement.
- Your progress is automatically saved.
- View your past wins to stay motivated!
